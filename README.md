## My first TCP port scanner built with Python.

### Requirements

Python 3.9 or newer. No third-party packages required.

### Installation

Clone the repository: git clone https://github.com/micaelaxvii/python-port-scanner.git

### Usage

Run the scanner with an IP address and a port range:

 python port_scanner.py --ip_address 127.0.0.1 --port_range 1 1024 The example uses 127.0.0.1, your own computer's loopback address.

The program also includes --verbose and --threads options.

--help for manual.
